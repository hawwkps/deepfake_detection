# Проект CV ML Yandex
## Используемые модели
За основу финальной части проекта был взята модификация CNN и ViT -  ConvMixer. Отличие данной модели является:
1. Depthwise Conv(kernel_size=K) смешивает информацию между соседними пикселями, но обрабатывает каждый канал независимо
2. Pointwise Conv(1x1conv) смешивает информацию по каналам 
## Основные улучшения
1. OneCyclerLR - позволяет динамически менять lr чтобы находить точки минимума lossfunc + умеет выходить из локальных точек минимума
2. Laplacian - добавляет 4 пространство, которое характеризует отклонения интенсивности цвета пикселя от среднего. Грубо говоря это 2 производная, которая определяет резкие изменения цвета
3. MeanStd - генератор изображения и камера могут иметь определенные свойства, из-за которых при нормализации среднее может быть не 0.5 при синусоиде а 0.38
4. TTA - т.к в Remake Images мы используем фотографии повернутые, то модель учиться запоминать и повернутые фотографии, поэтому можно отдельно прогнать модель по test выборке а потом по повернутой test выборке и подобрать оптимальные коэфиценты
5. GElU - В отличие от RelU не обрезает отрицательную часть нейрона
6. RemakeImages - искусственно зашумляем изображения, чтобы модель лучше отбрасывала шум, который сгенерирован авторами
7. Finding Threshold - не обязательно должен быть 0.5, можно подобрать прогоном по valid выборке и выбрать тот, при котором будет максимальная точность

U.P.D не использовал MedianBlur - потому что он зашумлял соседнии пиксели, и из-за этого модель плохо запоминала признаки

## Неудачные попытки

#### Типы моделей

1. Идея двухветочной модели: RGB + Residual (артефакты, шум и т.д.)
2. Многомерная (4 канала) ветка residual

#### Объяснение причины неудач

1. High-pass, Laplacian, Sobel усиливают не только артефакты генерации, но и обычный шум/текстуры
2. Различная информация от двух меток - в результате модель путается и/или переоценивает вклад residual-ветки
3. В целом идея четырёхканальной residual-ветки только увеличивает шум, не делая ничего полезного
